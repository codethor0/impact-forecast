# Impact Forecast Algorithm (IFA) Roadmap

This roadmap tracks potential enhancements and future factors for the Impact Forecast Algorithm (IFA).

## v1.x enhancements

- Additional example profiles (SaaS-heavy, OT/ICS environments, public sector).
- Support loading factor catalogs from YAML/JSON configuration.
- Export results to CSV/JSON for GRC and reporting pipelines.
- Jupyter notebook templates for exploratory analysis and demos.

## Longer-term ideas

- PyPI package publishing and versioned releases.
- Integration examples with SIEM / SOAR tooling.
- Web-based visualization front-end for IFA runs.
- Extended factor libraries mapped to MITRE ATT&CK and specific ransomware families.
